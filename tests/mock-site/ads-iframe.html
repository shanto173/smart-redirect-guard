Advertisements inside a cross-origin iframe

Test 15 — the hard limit of what any extension can do.

Below are two frames. The first is same-origin, the second is loaded from the other local origin and is therefore cross-origin.

Our content script can read and modify the DOM inside the same-origin frame. It can never read inside the cross-origin one: the browser's same-origin policy forbids it and no extension permission changes that. What the extension can still do is judge the iframe element from this page — its src host, its size and its position — and hide the whole frame if the host matches a rule, or let declarativeNetRequest block the request so the frame never loads at all.
