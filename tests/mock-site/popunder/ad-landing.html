Mock advertising landing page

Test 2 — this tab should close by itself.

This page stands in for an advertising landing page. It is served from this machine; no real ad network is involved.

Two things make it a confirmed advertisement to the extension:

  • its path matches the */popunder* rule, and
  • its host is registered as an example ad domain by srg-test-config.json.

If you are still reading this after a second or two, check that protection and new-tab protection are both on, and that you imported the test config.

Expected: closed after the configured delay, with the opener tab re-activated. If the host was not registered as an ad domain, staying open is the correct behaviour instead — the URL pattern alone is medium confidence, and medium never closes a tab.
